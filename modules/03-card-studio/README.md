# Cali Card Studio (Standalone Module)

Automated 9:16 vertical presentation card and graphic b-roll generator.

## Features
- **Strict Contain Scaling:** Full-body avatars are scaled with preserved aspect ratio inside dark navy letterboxing. Heads, hair, and footwear are never cropped or cut off.
- **Structured Sections:** Top category pills, bold titles, numbered checklists, and accent highlight boxes.
- **Batch Ready:** Generates high-resolution PNGs at 720x1280.

## Usage

```bash
python card_studio.py --art avatar.png --badge "SECURITY BRIEF" --title "Firewall Protocols" -o card.png
```
