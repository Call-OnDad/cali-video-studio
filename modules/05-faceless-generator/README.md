# Cali Faceless Video Generator (Standalone Module)

Autonomous text-to-video reel and b-roll explainer generator.

## Features
- Generates vertical 9:16 reels from background imagery or stock b-roll.
- Dynamic high-visibility caption box overlay.
- No avatar talking head required—ideal for faceless TikTok/Shorts channels.

## Usage

```bash
python faceless_generator.py \
  --image broll_server.jpg \
  --caption "How to host your own AI video studio in 2026" \
  --duration 6.0 \
  -o faceless_short.mp4
```
